# IPL 2026 Fan Portal

A responsive IPL-themed website built using HTML and CSS. This project showcases all IPL teams, match highlights, and a modern user interface inspired by the official IPL website.

##  Live Demo

 https://harinikumarijeyaraj.github.io/ipl-fan-portal/

##  Features

- Responsive Design
- IPL Team Pages
- Match Highlights Section
- Modern Dark UI
- Team Navigation
- Mobile-Friendly Layout
- Smooth Hover Effects

## Technologies Used

- HTML5
- CSS3
- GitHub Pages
